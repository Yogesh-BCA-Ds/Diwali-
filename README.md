🎆 AFTERGLOW — A Symphony of Light & Sound

«An interactive, cinematic fireworks experience built using HTML, CSS and JavaScript.»

AFTERGLOW transforms your browser into a night sky filled with beautiful fireworks, glowing particle effects and synchronized sound effects.

Experience a visual celebration powered entirely by frontend technologies — no external libraries, frameworks or paid APIs required.

✨ Features

- 🎇 Multiple Firework Patterns: Rings, hearts, willows, chrysanthemums and more.
- 🌌 Particle Physics: Dynamic particles with gravity, velocity, fading and glowing effects.
- 🚀 Launch Trails: Animated trails accompanying every firework launch.
- 🔊 Sound Effects: Launch whistles, deep bass explosions and crackling sounds using the Web Audio API.
- 🎵 Audio-Visual Synchronization: Sound effects triggered by actual firework events.
- 🎮 Interactive Experience: Launch fireworks by clicking or tapping anywhere in the sky.
- ⚡ Automatic Show: Enjoy continuously launching fireworks.
- 📱 Responsive Design: Designed for desktop and mobile screens.
- ⏯️ Playback Controls: Pause, resume, enable or disable automatic fireworks and sound.

🛠️ Technologies Used

Technology| Purpose
HTML5| Page structure
CSS3| Styling, layout and visual effects
JavaScript| Animation and particle physics
Canvas API| Fireworks rendering
Web Audio API| Procedural sound effects
SVG| City skyline illustration

🚀 Getting Started

No installation or dependencies required!

1. Clone this repository:
   
   git clone https://github.com/Yogesh-BCA-Ds/Diwali-.git

2. Open the project folder.

3. Open "afterglow_fireworks.html" in your browser.

4. Click Begin to start the experience.

5. Enable sound and enjoy!

Alternatively, download the HTML file and open it directly in a modern browser.

🎮 How to Interact

Action| Function
Click Begin| Start the fireworks show
Tap/click the sky| Launch fireworks at a chosen position
Auto Show| Enable or disable automatic launches
Sound| Enable or disable sound effects
Pause / Resume| Control the animation
Spacebar| Start the show
M key| Toggle sound

Note: Audio playback requires user interaction because of browser autoplay restrictions.
